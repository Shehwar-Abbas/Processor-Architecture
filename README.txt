## Important data note
This is a working front-end prototype with 78 representative processors (18 original + 60 added) and live keyword search with alias matching/ranking, filters, quick details, and 1–4 processor comparison across desktop, laptop, mobile, embedded and server categories. Benchmark fields intentionally say “Demo only / Not verified”; do not present these as real Geekbench results. Before a public factual release, replace them with dated scores from a consistent Geekbench Browser result and verify all model specifications from official product pages. The assignment brief itself requires only at least three real URLs about the chosen topic; it does not require hundreds of fully researched CPU records. The catalogue now includes Intel, AMD, MediaTek, Qualcomm, Apple, Samsung, Google, NVIDIA and IBM models. Search matches model names, manufacturers, families, device types and aliases.

## Run locally
Open `index.html` in a browser. No framework or install is needed.

## Deploy on GitHub + Vercel
1. Make/sign in to GitHub and create a repository, e.g. `processor-comparison`.
2. Upload `index.html` and `before.html` to the repository (drag-and-drop upload is fine).
3. In Vercel, choose **Add New → Project**, import this repository, keep the default settings, and click **Deploy**.
4. Copy the production URL (not the preview URL).
5. For the assignment's BEFORE evidence, deploy `before.html` as the initial `index.html` and take screenshots of the live page and View Page Source. Save that version in a separate GitHub branch/repository or take screenshots before replacing it.
6. Then replace `index.html` with the polished version, redeploy, and take AFTER screenshots. Make sure every screenshot shows the production address and your computer's date/time as the assignment requires.
